# Известные проблемы

Этот документ содержит только незакрытый технический долг. Закрытые проблемы
переносятся в раздел ниже вместе с проверяемой гарантией.

| Приоритет | Область | Наблюдаемая проблема | Условие приёмки |
|---|---|---|---|
| Medium | Backend | Редкие или неоднозначные названия остаются в «Прочее», когда локальные правила не подходят, а уверенность AI ниже 0.8. Каталог GTIN/aliases расширяется только подтверждёнными результатами новых чеков. | Regression corpus покрывает новые GTIN/aliases; низкоуверенный AI-результат не загрязняет каталог. |
| High | Backend/Mobile | QR-дубликаты должны схлопываться при синхронизации нескольких устройств по серверному хешу нормализованного фискального QR; ручные чеки не дедуплицируются. | Route и mobile sync tests подтверждают идемпотентность и изоляцию пользователей. |
| Low | Dev dependency | Полный `npm audit` сообщает один moderate advisory в `@hey-api/openapi-ts@0.97.0`; `0.97.3+` одновременно попадает под более серьёзный advisory parser | Mobile maintainers до 2026-09-01 обновляют/заменяют генератор, когда существует непротиворечивая безопасная версия; до этого используется только доверенный локальный OpenAPI |
| Low | Mobile/Backend | Локальный профиль целей и ограничений передаётся AI только с текущим запросом; доходы в v1 не собираются. | Unit-тесты и legal-тексты подтверждают отсутствие серверного хранения. |
| Medium | Backend/Mobile | Добавить 2 подписки: "Бюджетная" за 300 рублей, которая будет использовать AI_LIGHT_MODEL при любых внешних запросах к ИИ, и "Premium" за 800, которая будет давать возможность использовать AI_STRONG_MODEL (если AI_LIGHT_MODEL можно использовать для текущей задачи, то она будет использоваться). | Проверка оплаты фиксирует план и цену; model routing покрыт unit-тестами. |
