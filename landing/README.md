# Foodler landing

Отдельный Vite-лендинг Foodler в редакционном визуальном направлении. Страница
рассказывает о сканировании чеков, категориях расходов и информационных
подсказках Foodler AI; она не подключается к API и не содержит пользовательских
данных. Для страницы используется отдельная editorial-версия иконки Foodler;
основная мобильная иконка приложения не заменяется автоматически.

## Локальный запуск

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

Проверки:

```bash
npm run build
npm run test:sites
```

CTA через RuStore указывает на страницу пакета `com.Foodler.chih_pih`. Перед
публичным запуском нужно подтвердить, что идентификатор опубликован в RuStore.

Кнопка скачивания открывает выбор установки: RuStore или прямой APK. Для
прямого варианта при публикации лендинга нужно положить подписанный файл по
пути `public/downloads/Foodler.apk`.
