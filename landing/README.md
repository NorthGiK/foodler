# Foodler landing

Отдельный Vite-лендинг Foodler в редакционном визуальном направлении. Страница
рассказывает о сканировании чеков, категориях расходов и информационных
подсказках Foodler AI; она не подключается к API и не содержит пользовательских
данных.

## Локальный запуск

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

Проверки:

```bash
npm run build
npm run test:sites
```

Главный CTA указывает на страницу Google Play пакета
`com.Foodler.chih_pih`. Перед публичным запуском нужно подтвердить, что этот
идентификатор опубликован в Google Play.

## Контент

Советы в блоке Foodler AI — примеры информационных рекомендаций, построенных
на истории покупок. Блок «Здоровее» не является медицинской рекомендацией,
диагностикой или обещанием результата.
